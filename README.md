# Зажги квартал / Light the Block — 1.0.0

[Играть / Play](https://aineyroseti-glitch.github.io/light-the-block-demo/)

Поворачивайте провода, соединяйте источник со всеми домами и возвращайте свет в вечерний город. 60 уровней, 3 района, 14 отдельных задач дня и интерфейс RU/EN. Без таймера.

Rotate wires, power every house and bring an evening city back to life. 60 campaign levels, 3 districts, 14 separate daily puzzles and English/Russian UI. No timer.

Откройте index.html через статический HTTP-сервер или ссылку выше. Установка и сборщик не нужны. Прогресс сохраняется в этом браузере; в настройках доступны экспорт и импорт. Прогресс пилота 0.2.0 переносится автоматически на том же origin.

В этой автономной версии реклама и Яндекс SDK не загружаются. Все подсказки бесплатны. Задачи дня — конечный набор из 14 схем, затем архив.

This standalone version does not load ads or the Yandex SDK. All hints are free. Progress stays in this browser and can be exported/imported in settings. Daily puzzles are a finite bank of fourteen, then an archive.
