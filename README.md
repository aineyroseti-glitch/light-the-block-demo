# Зажги квартал

Браузерная головоломка: поворачивайте провода, соединяйте источник со всеми домами и возвращайте свет в вечерний квартал.

[Открыть демоверсию](https://aineyroseti-glitch.github.io/light-the-block-demo/)

Прототип 0.1.0: 12 основных и 3 бонусные задачи, подсказки, отмена хода и сохранение прогресса в браузере. Можно открыть index.html локально; для надёжного сохранения удобнее опубликованная версия. Зависимостей и сборщика нет.

Это ранняя демоверсия для технической проверки. Браузерная и мобильная приёмка ещё не завершены. Нет рекламы, покупок, SDK Яндекс Игр и облачной синхронизации. Локальный дневник теста экспортируется вручную и не отправляется игровому серверу.

Репозиторий содержит только публикуемые файлы игры. GitHub Pages обновляет сайт из ветки main.
