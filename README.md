# Зажги квартал

Браузерная головоломка: поворачивайте провода, соединяйте источник со всеми домами и возвращайте свет в вечерний квартал.

[Открыть демоверсию](https://aineyroseti-glitch.github.io/light-the-block-demo/)

Версия 0.2.0: 12 основных и 3 бонусные задачи, текстовые подсказки, отмена хода до победы и сохранение прогресса в браузере. Вечерний квартал загорается по мере прохождения; результат решения остаётся видимым. Можно открыть index.html локально; для надёжного сохранения удобнее опубликованная версия. Зависимостей и сборщика нет.

Это ранняя демоверсия. В Chrome прошли 60 автоматических проверок и отдельная приёмка всех 15 задач с проверкой мыши, клавиатуры, эмуляции касания и скачивания JSON. Проверены размеры 1280×720, 1280×900, 390×844, 360×740. Реальные телефоны и Safari пока не проверены.

Нет рекламы, покупок, SDK Яндекс Игр и облачной синхронизации. Локальный дневник теста экспортируется вручную и не отправляется игровому серверу. Прогресс предыдущей версии сохраняется.

Репозиторий содержит только публикуемые файлы игры. GitHub Pages обновляет сайт из ветки main.
